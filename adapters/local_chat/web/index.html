试试这些小互动

  1. 摸头按住头发，左右轻轻揉动；闭眼和倾头会跟着你。
  2. 戳脸、拍肩不同地方有不同反应，连续戳几次还有另一句回应。
  3. 拉拉手按住手，往两侧拖动。他会倾身跟随，松开缓缓回正。
  4. 递点小心意把茶或礼物拖到角色身上，也可以直接点道具。
  5. 聊天打开“和他聊聊”，输入文字或用麦克风说话。

也可使用右侧动作按钮。角色画布获得焦点时，1 摸头 / 2 戳脸 / 3 碰手 / 4 活动 / Esc 松手。
